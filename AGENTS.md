# Working in this repo

- We're in Phase 1, product discovery. Work on the product docs and get Sunny's approval before moving on to UX design, architecture, or implementation.
- Treat the [assignment](docs/assignment.md) as the source of truth. Use the [product requirements](docs/requirements.md) for scope and acceptance criteria.
- Use the [personas](docs/user-personas.md) and [journeys](docs/user-journeys-and-flows.md) to understand each role and the handoffs between them.
- Use the [workflow rules](docs/workflow-rules.md) for state transitions, permissions, and ownership.
- Track assumptions and open questions in the [decision log](docs/decisions.md). Record a decision as agreed once Sunny confirms it.
- Use plain language and consistent product terms. Keep each rule in one place and link to it from related docs.
